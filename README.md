# TRAFFIC LAB — 정체 연구소

> 배포 단계 안내(2026-10-09): 로컬 검토 후 사용자의 공개 배포 승인을 받았습니다. 아래 LOCAL ONLY/NOT_RUN은 배포 전 검토 기록입니다. 승인 후 실제 공개 결과는 [통합 배포 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)의 최신 배포 절에서 따로 확인합니다.

[실행](https://hyungminyoon1.github.io/traffic-lab/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/)

1 km 단일 차로에서 속도·차간 시간 개입을 같은 시드의 무개입 결과와 비교합니다. 기존 3개 도전과 자유 실험을 유지합니다.

## 직접 해보기

- 도전을 선택하고 시드 1–9999로 **새 도전 준비** → 사건 일정·중간 검사·최종 목표 확인
- 희망 속도와 목표 차간 시간을 함께 골라 30초/1점 또는 60초/2점 개입. 유지 중에는 교체할 수 없고 끝나면 원래 조건으로 복귀
- **재생** 또는 **10초 진행**으로 판단 시점을 관찰. **처음부터**는 같은 도전·시드로 다시 준비
- 중간 검사(직전 20초)와 최종 60초의 흐름·속도 편차·무개입 대비 개선을 모두 달성하면 성공
- 출발 상태, 내 도로/무개입 비교표, 두 평균 속도 그래프와 사용한 개입 기록 검토
- **현재 개입 저장/내보내기**: 도전·시드·개입 시각과 조건을 보관. **선택 정책 재생** 후 재생 또는 10초 진행으로 같은 조건을 다시 계산
- **정책 가져오기**: JSON 최대 4 KB, 예산·시각·중첩 검증. 기기 저장 최대 10개, 선택 삭제/전체 삭제 지원. 이름·계정·서버 업로드 없음
- **자유 실험**에서는 차량 수·희망 속도·차간 시간 변경, 도로 클릭/Enter로 3초 제동, 여유로운/붐비는 도로 프리셋 사용. 도전에서는 클릭/방향키가 차량 선택만 수행

## 세 가지 도전

| 도전 | 도로·사건 | 시간/예산 | 중간 검사: 20초 평균 | 최종 60초 목표 |
| --- | --- | --- | --- | --- |
| 파동을 흡수하라 | 48대, 20·55초 급제동 | 180초/4점 | 90초: 흐름 ≥1500, 편차 ≤25 | 흐름 ≥2000, 편차 ≤10, 무개입 대비 ≥125% |
| 병목 뒤의 회복 | 44대, 20–100초에 420–580 m 희망 속도 35 km/h, 65초 급제동 | 240초/6점 | 160초: 흐름 ≥1800, 편차 ≤12 | 흐름 ≥2000, 편차 ≤6, 무개입 대비 ≥125% |
| 세 번의 충격 | 60대, 25·80·140초 급제동 | 240초/5점 | 120초: 흐름 ≥1600, 편차 ≤8 | 흐름 ≥2000, 편차 ≤10, 무개입 대비 ≥150% |

흐름 단위는 대/시간, 편차는 km/h입니다. 모든 시드의 출발 위치·차량 수는 도전별로 같고, 시드는 작은 출발 속도 차이와 제동 차량 번호를 결정합니다. 선택된 시드는 고정되며 재생 배속으로 판정이 달라지지 않습니다.

## 무엇을 측정하나요?

평균 속도(km/h)와 평균 흐름(대/시간)은 다릅니다. 비교표의 흐름은 실제 모델 이동 거리 합계 ÷ 도로 길이 ÷ 측정 시간 × 3600입니다. 같은 속도여도 차량 수가 다르면 흐름이 달라집니다. 순환도로이므로 출구 처리량은 없으며 시작점 검지기의 누적 통과 대수는 따로 표시합니다. 속도 편차는 차량 속도 표준편차의 시간 평균으로 대열이 얼마나 고르게 움직이는지 보여 줍니다. 느린 차량은 7.2 km/h 미만입니다.

검지기 처리량은 같은 측정 구간의 시작점 통과 대수 ÷ 구간 초 × 3600입니다. 정지 시간은 0.1 m/s 미만 차량의 시간 합계(대·초). 시간 손실은 매 단계 각 차량의 max(0, 1 − 관측 속도 / 원래 도전 희망 속도) × 0.05초 합계(대·초)입니다. 구간 비교는 모델 관측 차이이며 실제 도로의 인과 효과가 아닙니다.

계산 간격 0.05초, 차량 길이 5 m, 최소 간격 0.2 m. 병목은 희망 속도만 바꿉니다. 개입은 30/60초이며 도전 종료 때 계산이 멈춥니다. 이 모델의 차간 시간은 실제 안전거리 권고가 아닙니다.

새로고침하면 현재 도로는 초기화되며 저장 정책은 남습니다. 직접 성공한 정책은 자동 저장되고, 저장된 정책을 다시 계산해 도전별 직접 완료 개수를 확인합니다. 가져오기·정책 재생은 직접 완료로 집계하지 않습니다. 완료 요약 `web-lab-progress-v1`에는 앱 ID·완료/전체 개수·갱신 시각만 쓰며, 갤러리와 시드·개입을 공유하지 않습니다. 전체 삭제는 이 앱의 정책과 완료 요약만 지웁니다. 저장 공간이 꽉 찬 상태에서 성공하면 항목 삭제 후 현재 개입을 저장하세요.

참고 개념: [원문과 추가 학습](https://traffic-simulation.de/info/info_IDM.html). 구현은 이 저장소의 계산 모델과 UI로 작성했습니다.

## 실행 및 검증

Node.js 22 이상. 외부 패키지는 없습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

main에 푸시하면 검증 후 dist만 GitHub Pages에 배포합니다. 순수 계산·정책 재생과 UI·기기 저장을 분리합니다. 서버 업로드·계정·방문자 추적·공개 순위 기능은 없습니다.

이번 도전 업그레이드는 **LOCAL ONLY**입니다. 커밋·푸시·배포·원격 쓰기는 수행하지 않았으며 위 공개 실행 링크에 새 기능이 반영되었다는 뜻이 아닙니다. 모델 검증과 실제 브라우저 검증은 [검증 기록](docs/verification.md)에서 구분합니다.
